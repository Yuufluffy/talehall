# Talehall

一个可安装到手机桌面的 AI 文字跑团应用。自由填写世界观 → AI 扮演 GM → 你既能扮演主角，也能以上帝视角把控剧情方向。

整个应用是**一个自包含的 HTML 文件**（约 380 KB），没有构建步骤、没有依赖、没有后端。

## 特性

- **单文件**：双击就能在电脑浏览器里用；放到任意静态托管上就能装成手机 App
- **自带上帝视角**：除主角视角外，可开启「导演」面板，查看幕后真相、下达剧情指令
- **世界观预设**：内置 10 套可切换预设（艾厄洛姆德大陆、冒险者开局、武侠、修仙、赛博、都市灵异、克苏鲁、末日、校园、空白），也可以从零写自己的世界
- **实时地图**：两层结构（好看的背景图 + AI 只读的语义层），AI 说地名，客户端换算坐标，AI 永远不会把位置算错
- **存档码**：把进度压缩成一段可粘进备忘录的文本，换设备贴回去即可续玩
- 文风语体、内容尺度、成败检定、叙事结构、思考程度、token 统计等均可调

## 在手机上使用

### 方式一：部署到静态托管（推荐，可安装成 APP）

把整个 `airpg-app/` 目录交给任意静态托管（Cloudflare Pages / Vercel / Netlify / GitHub Pages 都行），
然后在手机浏览器里打开那个网址。

- **Android (Chrome)**：地址栏右侧出现「安装」图标，或菜单 →「安装应用」
- **iOS (Safari)**：底部分享 →「添加到主屏幕」

装好后从桌面图标启动，是全屏无浏览器地址栏的，断网也能打开（剧情依然需要联网调用 AI）。

> 本项目当前部署在 **Cloudflare Pages**，从 GitHub 仓库自动构建发布。

### 方式二：电脑起本地服务，手机用 Wi-Fi 访问

```bash
cd airpg-app
npx serve          # 或 python -m http.server 8080
```

然后手机浏览器打开 `http://<电脑局域网IP>:端口`。
注意：非 HTTPS 的 http 地址下 Service Worker 不会注册（浏览器限制），
但不影响正常游玩，只是不能离线安装。

### 方式三：只想随便试试

把 `index.html` 传到手机（微信/网盘/邮件附件均可），用浏览器打开文件即可。
UI 已按手机适配，但 PWA 安装能力不可用。

## 实时地图

点顶栏的 **🗺 地图** 打开。手机上在「⋯ 更多」里。

### 设计思路

让 AI 看图是不靠谱的（又费 token 又不准）。所以地图做成**两层**：

```
背景层  你导入的图片（手绘 / 生成的地图 / 拍照）—— 只负责好看
语义层  你在编辑器里标的区域·标记·棋子      —— AI 只看这一层
```

关键约定：**AI 只用「名称」，从不使用坐标**。它说「把主角移到地窖」，
客户端自己把地窖的坐标换算出来。因此 AI 永远不会把位置算错。

### 使用流程

1. 点 **🗺 地图** → **✏️ 编辑**
2. （可选）**导入背景图** —— 支持 PNG / JPG / WebP / SVG，超过 1600px 会自动缩图并转成 WebP 压缩
3. 用工具画地图：
   - **📍 标记**：点一下 → 命名。类型有地点/人物/物品/出口/危险，颜色和图标不同
   - **▭ 矩形 / ⬠ 多边形**：框出房间、区域、地块（多边形连续点顶点，点「完成」或双击闭合）
   - **⬚ 选择**：点中后在右侧改名称/类型/备注/是否已揭示
   - **🗑 删除**：点一下移除
4. 把「地图名称」和每个元素的「备注」写清楚 —— 这些会直接进提示词
5. 游戏里把主角棋子放上去（在编辑器里新建一个阵营为「主角」的棋子），或者直接等 AI 帮你放

### 游戏中的实时变化

AI 每回合可以在状态块之后额外输出一个地图指令块，然后地图会自动变：

- 主角走到新地方 → 棋子带缓动动画滑过去，**镜头自动跟随**
- 揭示新区域 → 迷雾消失
- 发现新地点 → 标记出现在图上，**地图随着剧情自己长大**
- NPC 到场 → 新棋子出现

### 迷雾

开启后，未揭示的区域在游戏模式下完全不显示。
你在编辑器里仍然能看到它们的虚线轮廓，方便埋伏笔 ——
这正好和「上帝视角」的幕后真相互补：你知道那里有什么，玩家不知道。

### 缩放与平移

- 滚轮缩放；触屏单指拖平移、双指捏合缩放
- 右下角 ＋ / － / ⤢（适应窗口）
- 点/文字/描边的大小不随缩放变化，始终保持可读

### 分享与备份

**导出地图**会生成一个自包含的 `.map.json`（含背景图），可以直接分享给别人导入。
地图单独存在 `localStorage['airpg.maps']` 地图库里，存档只存一个引用；
而导出存档时会自动把地图一并打包，换设备导入就能完整还原。

### 把图片也给 AI 看（可选）

地图设置里有「图片一起发给 AI」。开启后，导入的背景图会作为图片输入一并发给模型。
**需要模型支持视觉**（如 GPT-4o / Gemini / Qwen-VL），DeepSeek-chat 这类纯文本模型会报错。
默认关闭 —— 因为结构化描述已经足够准确，而且更便宜。

## iOS / Android 双端适配说明

两边浏览器差异比想象中大，以下是分别处理的点：

| 问题 | iOS (Safari / WKWebView) | Android (Chrome) | 处理方式 |
|---|---|---|---|
| 软键盘遮挡输入框 | 不缩小布局视口，而是把可视区整体下移 | 配合 `interactive-widget=resizes-content` 直接缩小布局视口 | 用 `visualViewport` 同时跟踪 `height` 与 `offsetTop`，两者机制不同都覆盖 |
| 视口高度单位 | `dvh` 需 iOS 15.4+ | `dvh` 需 Chrome 108+ | `--app-h` 基础值给 `100vh`，再用 `@supports` 升级到 `dvh`；**绝不能直接写 `100dvh`**，否则老浏览器会把 `height` 整条声明丢弃 |
| 按钮按下反馈 | `:active` 需页面存在 touch 监听才生效 | 正常 | 注册一个空的 `touchstart` 监听解禁 |
| 安装到桌面 | 无 `beforeinstallprompt`，且只能用 Safari | 有 `beforeinstallprompt`，可程序化触发 | 双端分别接管，各自给对应的引导文案 |
| 返回键 / 手势 | 无系统返回键 | 返回键会直接退出页面 | 开抽屉时压入一条 history，返回键先关抽屉 |
| 状态栏颜色 | `apple-mobile-web-app-status-bar-style` 写死 | `theme-color` 可动态改 | 换主题时同步更新 `theme-color` |
| 退出前存档 | `beforeunload` 经常不触发 | 基本可靠 | 额外监听 `visibilitychange` 补存一次 |
| 字体 | 中文衬线有 Songti SC | 默认没有中文衬线，会 fallback 成无衬线 | 字体栈补上 `Noto Serif CJK SC` / `Noto Sans CJK SC` / `PingFang SC` / `Roboto` |
| `color-mix()` | 需 iOS 16.2+，不支持时整条声明失效 | 需 Chrome 111+ | 全部 16 处都补了普通降级声明 |
| 双击缩放延迟 | 有 | 有 | `touch-action: manipulation` |
| 长按呼出菜单 | 会弹出系统菜单 | 会触发文本选择 | `-webkit-touch-callout: none` + `user-select: none`（正文区不禁用，方便复制剧情）|
| 下拉刷新 | 一般无（但页面橡皮筋反弹） | 有，可能误触 | `overscroll-behavior: none/contain` |
| `<select>` 外观 | 滚轮选择器 | 弹窗列表 | `appearance: none` + 自绘箭头统一 |
| 表单聚焦缩放 | 字号 <16px 会强制放大整页 | 不会 | 输入框统一 16px |
| 存储回收 | ITP 会清理长期未访问站点的数据 | 低存储时系统会清 | 申请 `navigator.storage.persist()`；存档限额并提示导出备份 |

### 已知差异（无法完全抹平）

- **iOS 只能用 Safari 安装**。iOS 上的 Chrome / Firefox / 微信内置浏览器基于 WebKit，不支持「添加到主屏幕」，只能存书签。
- **iOS 没有 `beforeinstallprompt`**，安装必须用户手动操作，App 内只能给引导。
- **中文衬线字体**：iOS 自带 Songti SC；Android 多数机型没有中文衬线字体，会回退到思源宋体（若系统有）或默认无衬线。想要两端完全一致只能内嵌 Web 字体，但那样会破坏离线可用性，所以没做。
- **微信内置浏览器**：可以正常玩，但无法安装；另外微信对 `localStorage` 的清理策略更激进，建议及时导出存档。

## 手机端已做的适配

- **软键盘不再遮挡输入框**：用 `visualViewport` 实时计算可视高度并写回 `--app-h`；
  配合 `interactive-widget=resizes-content`，键盘弹出时界面自动收缩
- **状态面板 / 上帝视角面板改为底部抽屉**：从下方滑出，点遮罩收起，不再挤压叙事区
- **顶栏精简**：只保留 `📊 状态`、`👁 上帝视角`、`⋯ 更多`，其余收进「更多」抽屉
- **行动选项改为横向滑动条**，不再换行占满屏幕
- **世界构建页的动态行竖排**：势力/地点/人物那些多字段行，在手机上改为上下堆叠
- **输入框字号 16px**：避免 iOS 聚焦时强制放大页面
- **安全区适配**：`env(safe-area-inset-*)`，刘海屏与底部手势条不遮挡内容
- **触控目标 ≥ 44px**，去掉 hover 位移，加上 `:active` 反馈
- **所有 `prompt()` 换成自定义底部弹层**：系统弹窗在手机上体验差且部分内置浏览器会拦截
- **横屏适配**：矮屏时自动压缩顶部留白

## 数据与隐私

- API Key、存档、外观配置全部存在浏览器 `localStorage`，不会上传到任何服务器
- 请求直接从你的设备发往你自己填写的 AI 接口地址
- 想换设备：用「导出」生成存档 JSON，在新设备「导入」即可（含设定、外观、导演配置）
- 注意：浏览器清理站点数据会连同存档一起清掉，重要进度记得导出备份

## 自定义

- **主题**：设定页「⑤ 外观」，7 套预设 + 强调色/背景/字体/字号/行高/圆角/阅读宽度全部可调
- **AI 接口**：任何 OpenAI 兼容接口。只填地址、Key、模型名即可
  - DeepSeek `https://api.deepseek.com/v1/chat/completions`
  - OpenAI `https://api.openai.com/v1/chat/completions`
  - Ollama 本地 `http://localhost:11434/v1/chat/completions`（需要 `OLLAMA_ORIGINS=*`）
- **改状态栏字段**：编辑 `index.html` 里的 `stateSpec()` 与 `renderPanel()`
- **改输出契约**：编辑 `OUTPUT_SPEC()` 与 `GOD_SPEC`
